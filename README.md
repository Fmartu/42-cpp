# cpp-modules

My C++ modules from 42 Roma Luiss, 00 to 04, all in C++98. They used to be five separate repos, now they live together here.

| Module | Topics | What I built |
|---|---|---|
| [cpp00](cpp00) | classes, member functions, iostream | a megaphone and a tiny phonebook |
| [cpp01](cpp01) | memory, pointers and references, file streams | zombies on the stack and on the heap, weapons, a small `sed`, a complaint filter |
| [cpp02](cpp02) | operator overloading, canonical form | a fixed-point number class |
| [cpp03](cpp03) | inheritance | ClapTrap, ScavTrap and FragTrap |
| [cpp04](cpp04) | polymorphism, abstract classes, deep copies | animals with a brain |

Every exercise has its own Makefile:

```bash
cd cpp04/ex01
make
./polymorphism
```
